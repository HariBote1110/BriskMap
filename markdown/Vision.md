# BriskMap ビジョン

## 概要

Paper 向けの Web 地図プラグイン。Dynmap の代替を目指す。

## 動機

- 個人的な興味が起点。**実現性検証（[Benchmark.md](Benchmark.md)）で既存品に対する明確な優位が示せなければ開発しない。**
- 判断基準は [Decisions/0001-go-no-go.md](Decisions/0001-go-no-go.md) を参照。

## 解決したい課題

| 課題 | Dynmap の現状 |
|---|---|
| キャッシュが大きすぎる | 描画済み画像をズーム段ごとに保存するため肥大化する |
| 持ち出しにくい | 細切れの画像が大量（数十万〜数百万ファイル）で、コピー・転送が非効率 |
| 初回描画が遅い | サーバー側で画像を描くため、大きいワールドでは数時間〜数日 |

「持ち出しやすさ」の定義: **ファイルコピーが効率的であること**（ファイル数が少なく、容量が小さく、差分コピーが効く）。

## 基本方針（仮説段階）

1. サーバーは**描画せず**、地表部分のブロックデータを取り出して圧縮保存するだけにする。
2. 描画はブラウザ側（WebGL / WebGPU）で、見られた範囲だけ行う。
3. 2D（真上）と 3D の両方を、同じ元データから作る。
4. 保存単位はリージョン（512×512 ブロック）。1 ワールドあたり数百ファイル程度に抑える。

> 2・3 のブラウザ側描画は**要審議**。性能要件は [Requirements.md](Requirements.md) の未決事項を参照。

## 対象

- サーバー: **Paper のみ**
- 2D と 3D の両方を提供する

## 競合

| 製品 | 特徴 | BriskMap との関係 |
|---|---|---|
| **BlueMap** | 3D 表示。.mca を直接読み、サーバー側でメッシュを生成して保存。CLI 版あり | **最大の競合**。構想の大部分が重なる |
| Dynmap | 等角図。タイル画像を大量に保存。SQL 保存も可 | 置き換え対象 |
| squaremap / Pl3xMap | 真上 2D、軽量 | 2D のみの競合 |

## BlueMap に対する差別化の候補（未検証）

- 初回処理が桁違いに速い（描画をしないため）
- 保存容量が小さい（メッシュではなくブロックデータを保存するため）
- ファイル数が少ない（リージョン単位）
- Paper のイベントを受けて、ほぼその場で反映できる（BlueMap はワールドの保存待ち）
- Dynmap からの移行支援（マーカー・設定）
- 差分保存による過去の地図表示

## やらないこと（現時点）

- Paper 以外の対応（Spigot / Folia / Fabric / Forge）
- MOD ブロックへの対応
- テクスチャの同梱（Mojang の著作物のため。入手方法は別途決める）
